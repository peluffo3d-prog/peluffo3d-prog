## 🚀 Proyectos

### 🧠 [AtlasLibre](https://atlaslibre.app) — Atlas Anatómico 3D Gratuito

El Netter cuesta $100. AtlasLibre cuesta $0.

Atlas anatómico 3D completo, gratuito, web-first y en español. Único competidor web de Anatomy Learning, Complete Anatomy y Anatomía Atlas 3D que no requiere descarga ni pago. Incluye 636 estructuras en 3D con sistemas togglables, quiz mode, notas personales, logros, búsqueda global y links compartibles por estructura. +700 usuarios en las primeras semanas sin inversión en marketing.

Stack: Next.js · React Three Fiber · Three.js · TypeScript · Supabase · Groq API · Vercel  
Live: [atlaslibre.app](https://atlaslibre.app)

---

### 🤖 [Business Prospector](https://github.com/peluffo3d-prog) — Scraper de Leads para Negocios Locales

Herramienta de prospección automatizada que usa la Google Places API para encontrar negocios locales sin sitio web en cualquier zona de Argentina. Genera CSV listo para outreach con nombre, teléfono, rating y estado web de cada negocio.

Stack: Node.js · Google Places API · CSV export  
Uso: node prospector.js --rubro "carpintería" --zona "Morón" --radio 3000

---

### 💬 WhatsApp AI Agent — Bot de Atención con IA

Bot de atención al cliente por WhatsApp Business API (Meta oficial, no Baileys). Configuración por JSON, detección de intenciones, respeto de horarios, escalado a humano y contexto de conversación persistente. Arquitectura probada en producción para negocios argentinos.

Stack: Node.js · TypeScript · WhatsApp Business Cloud API · Anthropic API · Supabase

---

### 🛒 [CajaFlow / POS SaaS](https://github.com/peluffo3d-prog/pos-saas) — POS para Negocios Locales

Sistema de punto de venta completo para negocios argentinos. Gestión de productos, ventas, control de stock, historial y cierre de caja. Multi-usuario con roles.

Stack: Next.js · TypeScript · Supabase · PostgreSQL
