## 🚀 Proyectos

### 🧠 [AtlasLibre](https://atlas-libre.vercel.app) — Atlas Anatómico 3D Gratuito
El Netter cuesta $100. AtlasLibre cuesta $0.

Atlas anatómico 3D completo, gratis, web-first y en español. Único competidor web de Anatomy Learning, Complete Anatomy y Anatomía Atlas 3D que no requiere descarga ni pago. Incluye 636 músculos en 3D con sistemas togglables, quiz mode, notas personales, logros, búsqueda global y links compartibles por estructura.

**Stack:** Next.js · React Three Fiber · Three.js · TypeScript · Supabase · Vercel  
**Live:** [atlas-libre.vercel.app](https://atlas-libre.vercel.app)

---

### 🛒 [CAJA-CLARA](https://github.com/peluffo3d-prog/CAJA-CLARA) — POS SaaS para Kioscos
Sistema de punto de venta completo para kioscos argentinos. Gestión de productos e imágenes, ventas, control de stock, historial y cierre de caja. Versión anterior de pos-saas, enfocada en kioscos.

**Stack:** Next.js · TypeScript · Supabase · PostgreSQL

---

### 🤖 [bot-whatsapp-generico](https://github.com/peluffo3d-prog/bot-whatsapp-generico) — Bot de WhatsApp para Negocios
Bot de atención al cliente por WhatsApp, configurable para cualquier negocio mediante un único archivo JSON. Detecta intenciones por palabras clave, respeta horarios y notifica al admin cuando se necesita intervención humana. Sin IA, sin costo de API.

**Stack:** Node.js · JavaScript · whatsapp-web.js

### 🎨 [maneyraostudio](https://github.com/peluffo3d-prog/maneyraostudio) — Portfolio / Landing Page
Portfolio web para un estudio creativo, publicado con GitHub Pages.

**Stack:** HTML · CSS
