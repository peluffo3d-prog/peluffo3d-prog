# Hola, soy Jasiielo 👋

Desarrollador full-stack de **Matanza, Argentina**. Construyo productos SaaS, bots y herramientas para negocios reales.

---

## 🚀 Proyectos

### 🛒 [CAJA-CLARA](https://github.com/peluffo3d-prog/CAJA-CLARA) — POS SaaS para Kioscos
Sistema de punto de venta completo para kioscos argentinos, con gestión de stock, historial de ventas, cierre de caja y carga de imágenes de productos.

**Stack:** Next.js · TypeScript · Supabase · PostgreSQL

---

### 🏪 [pos-saas](https://github.com/peluffo3d-prog/pos-saas) — POS SaaS Multi-Tenant
Plataforma de punto de venta multi-tenant. Cada negocio tiene su propio espacio aislado con sus productos y ventas.

**Stack:** Next.js · TypeScript · Supabase

---

### 🤖 [bot-whatsapp-generico](https://github.com/peluffo3d-prog/bot-whatsapp-generico) — Bot de WhatsApp para Negocios
Bot de atención al cliente por WhatsApp, configurable para cualquier negocio mediante un único archivo JSON. Detecta intenciones, respeta horarios y notifica al admin cuando se necesita intervención humana.

**Stack:** Node.js · JavaScript · whatsapp-web.js

---

### 🎨 [maneyraostudio](https://github.com/peluffo3d-prog/maneyraostudio) — Portfolio / Landing Page
Portfolio web para un estudio creativo, publicado con GitHub Pages.

**Stack:** HTML · CSS
